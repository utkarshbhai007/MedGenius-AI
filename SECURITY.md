## Reporting a Vulnerability

Security is paramount for healthcare AI platforms handling medical data. If you discover a security vulnerability in MedGenius AI:

1. Please do **NOT** open a public issue.
2. Report vulnerabilities privately by emailing the maintainers or opening a private security advisory on GitHub.
3. Include detailed steps to reproduce the issue and any proof-of-concept demonstrations.
4. We will acknowledge receipt within 48 hours and work with you on a timely resolution.
